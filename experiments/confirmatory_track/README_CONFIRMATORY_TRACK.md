1. **분석층은 실제로 작동한다** — 틀린 설계를 준 대조군이 0점에 붙어 "형식이 아니라 내용"임이 분리 증명됐다(CT-01, CT-06H, CT-07 모두 재현).
2. **깊이가 관건이다** — 얇은 5필드는 씬을 낳지 못하고(r 0.21), 후판 10필드는 낳는다(r 0.81). 이것이 THICK 사양의 실측 근거다.
3. **현재 병목은 데이터가 아니라 채점 계측기다** — 같은 자료를 재도 채점자 일치도가 0.77~0.80으로 출렁여 판정이 세 번 막혔다. 관측 자체는 세 번 모두 같은 방향이었다.
